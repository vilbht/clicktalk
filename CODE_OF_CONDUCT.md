# Code of conduct

EucLink follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep discussion about the work.
Harassment, insults, personal attacks, sexualised language and publishing other people's
private information are not accepted, in issues, pull requests or anywhere else the project
is represented.

## Reporting

To report behaviour that breaks this code, open a private report under
**Security > Report a vulnerability** and start the title with "Conduct". Only the
maintainer sees it. You can also use GitHub's **Report content** option on any comment.

Reports are handled in confidence. The maintainer may remove comments, lock threads, or
block people from the project, following the enforcement guidelines of the Contributor
Covenant.
